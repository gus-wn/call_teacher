# 🔔 교무실 호출 시스템 (call_teacher)

교무실 문 앞 태블릿에서 학생이 배치표의 선생님 이름을 누르면,
교무실 안 PC·태블릿에서 **"띵동~ 김민수 선생님, 10203 홍길동 학생이 찾아왔습니다"** 하고 소리와 음성으로 알려 주는 웹 페이지입니다.

## 화면 구성

| 파일 | 어디에 띄우나요 | 하는 일 |
|---|---|---|
| `kiosk.html` | 교무실 문 앞 태블릿 | 배치표에서 선생님 선택 → 학번·이름, 용건 입력 → 호출 |
| `receiver.html` | 교무실 공용 PC / 각 선생님 PC·태블릿 | 띵동 소리 + 음성 안내, "곧 나갈게요 / 잠시만 / 다음에" 답장 |
| `setup.html` | 아무 기기 | 자리 배치, 교무실 이름, 연결 코드 설정 |
| `config.js` | — | 모든 기기에 공통으로 적용되는 기본 설정 |

## 처음 설정하기

1. 저장소 **Settings → Pages**에서 Branch를 `main` / `(root)`로 두고 Save → 잠시 후 `https://gus-wn.github.io/call_teacher/` 주소가 생깁니다.
2. `setup.html`에서 자리 배치를 채우고 **연결 코드 새로 만들기**를 누릅니다.
3. **config.js 내용 복사** → GitHub에서 `config.js`를 열어 연필(✏️) 버튼 → 전체를 붙여넣고 Commit.
4. 바로가기 주소 두 개를 각각 문 앞 태블릿 / 교무실 PC에서 엽니다.
5. 교무실 PC에서 **시작하기**를 한 번 누르면 끝 (브라우저 정책상 소리를 켜려면 한 번 눌러야 합니다).

### 운영 팁
- **개인 자리에서만 받고 싶다면**: 수신 화면 위쪽 "보여줄 선생님"에서 본인 이름을 고르면 내 호출만 울립니다.
- **40초 동안 아무도 확인하지 않으면** 한 번 더 알려 줍니다.
- 한 명이 확인하면 다른 기기의 알림도 자동으로 "확인됨"으로 바뀝니다.
- 태블릿은 **화면 자동 꺼짐 해제**, 가능하면 안드로이드 '앱 고정' 또는 iPad '사용법 유도 접근'으로 키오스크 화면만 보이게 해 두세요.
- 교무실 PC는 브라우저 탭을 닫거나 절전 모드로 들어가면 알림을 받지 못합니다.

## 동작 원리

GitHub Pages는 화면만 보여 주는 정적 사이트라서, 기기 사이에 실시간 신호를 전달할 중계 서버로
가입 없이 쓸 수 있는 공개 알림 서비스 [ntfy.sh](https://ntfy.sh)를 사용합니다.

```
[문 앞 태블릿] --호출--> ntfy.sh (연결 코드 채널) --실시간--> [교무실 PC]
             <--답장--                            <--
```

### ⚠️ 알아 두실 점
- ntfy.sh의 채널은 **코드만 알면 누구나 보낼 수 있고 볼 수도 있습니다.** 연결 코드는 추측하기 어렵게 만들어 주세요.
- 전송되는 내용은 학번·이름·용건 정도이며 서버에 짧게(최대 약 12시간) 보관됩니다.
- 장난 호출이 많아지거나 더 확실한 보안이 필요하면, 학교 계정의 Firebase 등으로 중계 서버를 바꾸는 방법이 있습니다.
