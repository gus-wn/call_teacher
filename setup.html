기본 정보

학생용 화면과 교무실 수신 화면은 같은 연결 코드를 써야 서로 연결돼요.

자리 배치

칸마다 위 칸에 이름, 아래 칸에 담당 업무를 적어요. 이름을 비우면 빈자리, 세로줄 전체를 비우면 통로가 돼요. 이름 앞에 #을 붙이면 표지(예: #출입문)가 돼요.

줄 칸

모든 기기에 저장 (GitHub)

버튼 한 번으로 GitHub의 config.js를 고쳐 학생용 화면·수신 화면 모두에 반영해요. 저장 후 1~2분 뒤에 적용돼요.

토큰은 어떻게 만드나요?
  1. GitHub 토큰 만들기 페이지를 열어요.
  2. 이름은 아무거나, 만료일은 원하는 기간으로 정해요.
  3. Repository access에서 Only select repositories → call_teacher만 골라요.
  4. Permissions → Repository permissions → Contents를 Read and write로 바꿔요.
  5. Generate token을 누르고 나온 값을 위 칸에 붙여넣어요.

토큰은 이 기기의 브라우저에만 저장돼요. 공용 기기에서는 저장 후 토큰 지우기를 눌러 주세요.

다른 저장 방법

이 기기에만 저장 — 이 브라우저에서만 바뀐 배치표가 보여요.
config.js 직접 고치기 — 아래 글상자를 직접 고친 뒤 글상자 내용 적용을 누르면 위 배치표에도 반영돼요.

바로가기 주소

연결 코드가 들어간 주소예요. 즐겨찾기에 넣어 두면 편해요.
