기본 정보

키오스크 태블릿과 교무실 수신 화면은 같은 연결 코드를 써야 서로 연결돼요.

자리 배치

칸마다 선생님 이름을 적어요. 담당 업무도 보여 주려면 이름|업무 (예: 박경훈|2-9/체험학습/세계사)로 적어요. 비워 두면 빈자리, 세로줄 전체를 비우면 통로, #을 앞에 붙이면 표지(예: #출입문)가 돼요.

줄 칸

저장하기

방법 1 이 기기에만 저장 — 키오스크 태블릿에서 직접 이 페이지를 열어 저장하면 가장 간단해요.
방법 2 모든 기기에 적용 — 아래 내용을 복사해 GitHub 저장소의 config.js에 붙여넣으면 모든 기기에 반영돼요.

바로가기 주소

연결 코드가 들어간 주소예요. 즐겨찾기에 넣어 두면 기기마다 따로 설정하지 않아도 돼요.
